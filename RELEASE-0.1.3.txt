CatLibrary 0.1.3（2026-11-11）

一、分级过滤覆盖所有入口（问题修复）
- 新增 filterLibraryIndex()，被标记的内容现在在这些地方也彻底隐藏：
  分类页、收藏页、首页计数与最近入馆、画板添加素材、画板面板内容、
  封面选择器、模型背景选择器、详情页同分类列表与标签建议。
- 直接访问被隐藏条目的 URL 时，详情页显示「内容不存在或已被分级隐藏」，不再白屏。

二、视频条目支持多集（问题修复）
- 新增后端命令 list_video_tracks：递归收集 source 下所有视频文件并按集数自然排序。
- 详情页新增选集条：上一集 / 下一集 / 直接点集号；一集播完自动接下一集。
- 单文件条目行为不变（仍是单个播放器）。

三、视频封面（问题修复）
- 新增后端命令 set_video_cover / delete_video_cover，与音乐封面同一套机制。
- 详情页右上角新增「设置封面」（从图片库挑图，尊重分级过滤）与「移除封面」。
- 修掉一个连带问题：给视频设过封面后原本会走图片分支、导致没法播放，现在视频条目始终显示播放器。

四、首页视频封面发黑（问题修复）
- 根因：视频条目没有图片封面时，卡片与首页只能画深色渐变兜底。
- 现在卡片与首页都会把视频定位到极小时间点、强制解码一帧当封面（preload=metadata，不整段下载）。

五、导入上百章时布局被挤坏（问题修复）
- 导入弹窗中间内容改为可滚动区域（min-h-0 + overflow-y-auto），底部按钮固定不随内容移动。
- 文件列表容器加 shrink-0，不再被长内容压扁到看不见；章节映射预览只列前 6 个文件名 + 总数。

六、新增「小说」分类（需求）
- 分类键 novels，目录约定 novels/novel_N/{cover,source}，卡片、导航、首页藏室、收藏页签都已接入。
- 新增后端命令 list_novel_chapters（递归列章节）与 read_novel_text（UTF-8 / UTF-16 BOM / GB18030 自动识别，
  中文 GBK 文本不会乱码；单文件上限 8MB）。
- 新增 NovelReader 阅读器：左侧章节目录、右侧正文、上一章/下一章、字号调节、记住上次读到的章节。
- 条目源内容计数与卡片摘要改成「N 章」。

七、大夕瓜桌宠两套角色入库（需求）
- 该桌宠不是 Cubism 模型，而是分层 PNG 骨架（manifest.json + 14/17 张图层）。
- 已导入：live2d_2 = 夕-温柔，live2d_3 = 夕-睡衣；封面由图层按顺序合成。
- 新增 RigViewer 分层骨架播放器：呼吸缩放、整体摆动、定时眨眼、视线跟随鼠标、点击开口说话。
- list_live2d_sources 增加 rig 字段探测 source/rig/manifest.json，Live2D 面板在没有 Cubism 模型时自动使用它。

八、验证
- TypeScript 类型检查通过，前端 9 项测试通过，Vite 构建通过，Tauri Release 构建通过。

九、已知事项
- xi-05（夕-睡衣）的 manifest 本身存在左右镜像的 id 与文件名错位，按原样保留未改。
- 新增分类/条目默认分级仍是「全年龄」，需要的话可再执行一次全库 18+ 标记。
- 便携版 D:\CatLibrary 需要手动替换 exe 与 dll 后才生效。
