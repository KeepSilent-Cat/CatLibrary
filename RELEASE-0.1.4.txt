CatLibrary 0.1.4（2026-11-12）

一、新增「报道」板块（需求）
位置：左侧导航「画板」下面，路由 /reports。

- 报道列表：卡片式（自动取第一篇图片块当封面），显示标题、副标题、内容块数与更新时间；
  新建、删除（两段确认）都在列表页完成。
- 块级编辑器（像搭积木）：大标题 / 小标题 / 正文 / 引用 / 图片 / 视频 / 音乐 / 分割线。
  每个块可上移、下移、在下方插入、删除；文本块高度随内容自动撑开。
- 编辑 / 预览一键切换：预览模式隐藏所有编辑控件，按最终排版显示。
- 素材直接从库里挑：图片从图片分类的预览图与封面里选，视频从该条目的所有集里选，
  音乐从该条目的曲目里选；选择器沿用分级过滤，被隐藏的内容不会出现在候选里。
- 自动保存：停止输入 700ms 后写盘，右上角显示「保存中… / 已自动保存」。
- 存储位置：素材库同级的 data/reports.json（跟着库一起搬走，不进 localStorage）。
  写入采用「先写 .tmp 再改名」，避免写到一半断电损坏文档。

二、后端接口
- load_reports(resource_root) → 全部报道（文件不存在返回空数组，不报错）
- save_reports(resource_root, reports) → 整体写入，原子替换

三、验证
- TypeScript 类型检查通过，Vite 构建通过，Tauri Release 构建通过，前端 9 项测试通过。

四、已知事项
- 报道里的媒体记录的是库内路径；素材被删除后，对应块会显示空白（不会崩）。
- 报道本身暂时没有内容分级字段；候选素材仍按当前分级过滤生效。
- 便携版 D:\CatLibrary 需要替换 exe 与 dll 后才生效。
