# CatLibrary 0.2.0 改动与验证说明

## 内容显示与分级

- 每次启动仅显示全年龄内容，不记住上次解锁状态。设置中选择扩大显示范围时使用密码弹窗；口令以摘要校验，输入不保存。
- 既有元数据第一次载入前会保留原始备份，再将旧条目统一设为18+；缺省分级及后续新增条目也为18+。迁移标记避免重复重置用户之后手工修改的全年龄标记。
- 首页计数、随机预览、各分类及收藏均按显示范围过滤。详情路由也检查分级；锁回全年龄会停止受限音乐，隐藏自定义背景。
- 画板和报道独立记录分级，未明确标记的旧内容和新内容均按18+处理。解锁后可改为全年龄。
- 这是本机应用的显示控制，不是对磁盘原文件进行加密。

## 首页、导航与收藏

- 首页增加随机馆藏轮播，约7秒切换，避免连续重复，可暂停，悬停与聚焦时暂缓。
- 补充收藏、画板、报道/频道入口。
- 侧栏顺序：小说、图片、漫画、音乐、视频、游戏、Live2D、截图、画板、报道、收藏，保留首页与设置。
- 收藏页补齐音乐、Live2D、画板、报道；画板当前项和报道列表可添加/取消收藏。

## 图片、视频与阅读

- 图片阅读器提供“移动单张图片”，明确选择原图与目标合集，确认后移动真实本地文件。翻页模式优先选择当前页；长图/网格模式需要明确选择图片。
- 目标同名文件不覆盖，路径越界被拒绝；复制成功并同步落盘后才删除原图，失败尽量保留原图。不能把高分级图片移动到低分级合集。
- 移动后刷新索引，记录路径映射，应用内报道引用可跟随调整；应用之外的引用需使用者自行调整。
- 视频可以直接将当前已解码画面保存为PNG封面，无需从图片库另选。新封面写入成功后才清理旧封面。
- 图片/漫画及其他详情编辑栏默认收起。
- 分类列表记忆会话内页码和排序，返回不会从第15页跳回第一页；显示范围或条目数量变化时，显示页码会限制在可用范围内。

## 持续音乐

- 播放器放到页面外层，离开专辑详情后音频元素不卸载，播放位置保持。
- 浮窗可暂停、继续、上一首/下一首、拖动进度，支持展开完整播放器、停止并关闭。
- 重锁全年龄时，受限内容会自动停止。

## 备份与迁移

- 设置中新增“保存备份检查点”和“恢复设置快照”。检查点保存本地设置、收藏、画板、阅读选项、元数据及迁移说明，不复制巨大素材库。
- 提示会列出当前资源目录、应复制的父文件夹、程序实际位置，避免把准备快照误认为已经完成整库备份。
- 恢复操作先确认，导入设置失败会回退原本的本地设置；不会覆盖素材文件。恢复后界面重新启动并恢复全年龄锁定。
- 记录旧库根目录，已知库内报道媒体路径可随换盘符重映射；外部文件不猜测、不擅自移动。
- 操作步骤见[备份与迁移](备份与迁移.md)。

## 验证与边界

- TypeScript检查、生产构建通过。
- 前端18项测试通过，包含直接详情访问限制、重启锁定、收藏不丢、15页往返、跨页音频不重建、重新锁定停止、随机轮播、移动/换盘路径引用。
- Rust 7项测试通过，覆盖旧分级只迁移一次、原元数据保留、移动单图、不覆盖、不接受越界路径、坏封面保留原封面、成功封面替换、设置快照结构和已有WebView存储迁移。
- 后台浏览器使用独立示例数据检查全年龄计数、密码弹窗及解锁、实际视频当前帧捕获并发送保存命令。没有读取私人资料库，也没有宣称已人工完整体验所有私有资源。
- Windows x64程序及MSI安装包构建成功。NSIS工具下载超时，改用本机已有WiX构建MSI；不是运行时需要用户额外安装NSIS/WiX。
- 原Live2D渲染、已有WebView2启动兼容逻辑保持。
