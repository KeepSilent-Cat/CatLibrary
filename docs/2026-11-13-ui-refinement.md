# Cat Library 0.2.1：界面融合与音乐播放优化

## 本轮改动

- 首页「藏室」保持同一套卡片布局，画板、报道与图片等入口并列；移除额外添加的首页收藏入口，侧栏收藏保留。
- 随机馆藏轮播增加左右两侧切换按钮，自动随机切换和悬停暂停继续保留。
- 解锁密码窗改为与应用一致的圆角毛玻璃样式，提供显示密码、错误反馈与解锁状态。
- 备份入口移到设置页右侧的路径说明下方。保存检查点、关闭应用、复制完整目录的步骤清晰区分；恢复设置也使用同主题确认窗。
- 音乐详情页显示完整播放器，离开详情后才出现精简悬浮播放器；返回专辑时恢复详情布局。同一音频元素在两个位置间移动，保持当前歌曲和播放进度。
- GitHub README 重新编排，增加直达官网介绍/下载的入口。源码仓库不附带私人素材库。
- 为仓库根目录的 library、data、backups、downloads 以及 exe/msi 增加忽略规则；不影响 src/data 源码目录。

## 保留的 0.2.0 能力

启动全年龄模式、18+ 默认分类、解锁显示、全板块收藏、图片跨合集移动、视频当前帧封面、列表返回分页记忆、Live2D 背景以及设置检查点均保留。详见 [0.2.0 改动与验证](2026-11-12-upgrade.md)。

## 验证

- TypeScript 类型检查通过。
- 24 项前端测试通过，覆盖首页入口、手动/自动轮播、密码交互、备份/恢复确认、页面返回和音乐挂载行为。
- 7 项 Rust 测试通过。测试只使用临时构造的小文件，未扫描私人素材；系统临时目录写权限受限时改用仓库忽略的 tmp/rust-fixtures。
- 隔离的无头浏览器使用虚拟馆藏、合成视频与音频，验证默认隐藏计数、密码解锁、视频取帧和同一音频元素在详情/悬浮/详情间持续播放；检查密码窗与播放器截图。
- 实际私人素材库的运行效果由使用者打开应用验收；测试未操作桌面界面。

## 使用

正常打开 D:\CatLibrary\cat_library.exe。进入音乐详情时不会弹出右下角播放器；播放后离开详情，右下角保留进度与播放控制。

备份时进入「设置 → 备份与迁移 → 保存备份检查点」，按返回说明正常退出应用后复制完整目录。检查点保存配置，不代表大型素材已被复制。
