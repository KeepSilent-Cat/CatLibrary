# Live2D 标注工作台

在应用内直接给立绘标节点，为后续绑定 / 桌宠动作准备数据，不用再切到外部工具。

## 入口

角色详情页（Live2D 分类）→ 顶部 **「标注工作台」**。

## 能做什么

- **载入基准图**：默认取 `source/rig/基准图.png`，没有就退回 `cover/cover.png`、再退回各分层 PNG；右下角可以手动切换。
- **逐项提示**：左侧按部位分组，右侧显示「这一步该点哪里」，包含：

| 部位 | 标注内容 |
|---|---|
| 全身 | 外框轮廓、左右脚接触点、躯干中心 |
| 头脸 | 脸部范围、下巴、头颈连接点 |
| 眼睛 | 左右瞳孔中心 / 内外眼角 / 上下眼睑 / 虹膜范围（12 项） |
| 眉毛与嘴 | 眉毛端点、嘴中心、嘴部范围 |
| 头发 / 角 / 耳 / 饰品 | 发根、发梢、角根/角尖、耳根、尾根/尾尖 |
| 衣服 | 领口、左右肩、腰线、上衣范围、下摆范围 |
| 手臂与腿 | 左右肩/肘/腕/掌心，左右髋/膝/踝/脚底 |
| 尾巴 / 特效 | 尾根、尾中段、尾尖、外轮廓 |

- **交互**：点空白落点；拖蓝点微调；拖空白平移；`Ctrl + 滚轮`或工具栏按钮缩放；撤销/重做；恢复视图。
- **轮廓**：进入「范围/轮廓」步骤后连续点击顶点，点「闭合轮廓」结束（至少 3 个点）。
- **不可见**：被头发或衣服挡住、画面上看不到的节点，点「此项不可见」，记录里记 `invisible`，不会伪造坐标。
- **自动保存**：改动 800ms 后写入 `library/live2d/<角色id>/data/annotations.json`，顶部显示「已自动保存」。
- **导出 JSON**：把当前标注导出成文件，便于交给外部绑定工具或做数据统计。

## 数据结构

```json
{
  "version": 1,
  "image": "D:\\CatLibrary\\library\\live2d\\live2d_4\\source\\rig\\基准图.png",
  "canvas": { "w": 1254, "h": 1254 },
  "points":    { "eye.l.pupil": { "x": 712, "y": 468 } },
  "polygons":  { "eye.l.iris": [ { "x": 690, "y": 450 } ] },
  "invisible": { "horn.root": true },
  "updatedAt": 1763500000000
}
```

`points` / `polygons` / `invisible` 的 key 是稳定 id（形如 `部位.子项`），改 UI 文案不会破坏已有数据。

## 与外部工具的关系（调研结论）

本地调研记录在 `D:\mvp_project\deepseekagi\夕_标注工作台\research\分层项目调研.md`，要点：

- **See-through**（<https://github.com/shitagaki-lab/see-through>）：单图 → 语义分层 + 遮挡补全 + PSD 导出，最多 23 个语义层；**不是完整绑定器**，细分网格与动作仍需另做。默认 1280 分辨率约需 12–16GB 显存（量化版约 8GB），本机 RTX 3050 Laptop 4GB 跑不动，所以**不在本机训练**。
- **Qwen-Image-Layered**：通用分层备选，不保证输出恰好符合角色骨架的固定部件。
- **Stretchy Studio**（<https://github.com/MangoLion/stretchystudio>）：已有分层素材后的图层/节点/网格绑定参考，明确支持接入 See-through 的分层结果。

因此本工作台的定位是：**先把节点、层关系和「哪里看不见」记录下来**，再交给成熟绑定器；确需拆新立绘时，才考虑用 See-through（需更强显卡）。

## 图层比对工作台（2026-11-18 重做）

角色详情页现在有两个入口：**图层比对**（默认，推荐）和 **节点标注**（早期版本，保留）。

### 图层比对做的是什么

像 PS 一样把 `art/*.png` 按顺序叠起来，重点解决「哪一层被挡了多少、偏移对不对」：

- **图层列表**（左）：上面 = 更靠前；眼睛图标切显示/隐藏；↑↓ 调整前后顺序。
- **画布**（中）：顶部/左侧有**坐标尺**，鼠标处有十字线与 `x / y` 实时读数，便于比对偏移。
- **选中层高亮**：其它层自动降到 35% 透明度（可关闭），一眼看清是哪一层。
- **遮挡自动计算**：选中某一层时，程序把「这一层的不透明像素」与「它上面所有层的不透明像素」做交集，
  被盖住的部分用**红色呼吸遮罩**标出来，右下角同时显示「遮挡 xx.x%」。
  这是逐像素算的，不需要你手动标「不可见」。
- **偏移微调**（右）：X / Y 数字输入 + 方向键（Shift 一次 10px），实时看对齐效果。
- **自动保存**：图层顺序、偏移、隐藏状态写到 `library/live2d/<id>/data/layers.json`。

### 与「节点标注」的分工

| 工作台 | 用途 |
|---|---|
| 图层比对 | 看层级、查遮挡、调偏移；遮挡由程序自动检测 |
| 节点标注 | 需要具体关节/眼睛坐标时，手工点出点位并回填 `rigOptions` |

### 实现说明

遮挡检测在离屏画布上做，长边压到 900px 以内以控制耗时（1280 画布约 90 万像素，单次计算几十毫秒）；
遮罩用 `requestAnimationFrame` 做呼吸透明度，不参与主画布合成，所以不拖慢拖动/缩放。
