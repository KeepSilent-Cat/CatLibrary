# 备份与移动硬盘迁移

## 日常操作

1. 在设置里确认“资源根目录”正确，点击“保存备份检查点”，等到出现“备份准备完成”。
2. 按提示记录快照位置、要复制的文件夹和程序位置，然后正常退出CatLibrary。
3. 将提示的完整资源库父文件夹复制到移动硬盘。默认布局就是复制整个 `D:\CatLibrary`，不要只复制 `library`。
4. 如果提示程序在另一位置，还需一并复制程序目录；绑定在库外的游戏或其他外部文件也需单独备份。
5. 在新电脑或新盘符下，打开复制后的程序。库根目录可从exe同级的 `library` 重新定位；仍指向旧位置时，在设置里选择复制后的资源根目录。
6. 收藏、画板等没有出现时，使用设置里的“恢复设置快照”，选择这次检查点的 `web-settings.json`。确认后界面重新载入，默认仍为全年龄。
7. 确认新副本的资料和功能正常后，再自行决定是否处理旧副本。

**保存检查点只准备小型配置快照，不会替你把整库复制到硬盘。** 备份完成与否取决于之后是否复制了完整目录和外部依赖。

## 各部分放在哪里

| 内容 | 典型位置 |
|---|---|
| 便携程序 | 根目录的 `cat_library.exe`、`cat_library_lib.dll` |
| 原始素材、各分类、报道子仓库 | `library` 及其子目录 |
| 标题、标签、分级等元数据 | `data/metadata.json` |
| 首次18+迁移前的元数据 | `data/metadata.before-adult-default.json` |
| 已完成分级迁移的标记 | `data/metadata.adult-default-v1`，迁移时一起保留 |
| 备份检查点 | `data/backup-checkpoints/时间戳/` |
| 收藏、画板、显示偏好等便携快照 | 检查点内的 `web-settings.json` |
| 当前机器的浏览器存储 | 用户AppData里的CatLibrary WebView目录，通常不在便携根目录 |

过去直接复制整个根目录，通常已经带走素材和元数据；但不能保证带走AppData里的收藏、画板和设置。因此现在先导出检查点，再复制完整根目录。

## 恢复注意

- 选择的是 `web-settings.json`，不是 `metadata.json`。设置恢复按钮只恢复本地设置，不把元数据或原文件覆盖到磁盘。
- 元数据、报道和原件通过复制完整目录迁移；旧元数据备份用于人工回滚，不要把它当成设置快照导入。
- 已知库内媒体路径会根据旧库根目录和图片移动记录重映射；库外引用不能保证包含在整库副本内。
- 不依赖重新复制浏览器缓存或重新安装Node.js。桌面程序仍需要Windows支持的WebView2运行环境。
